# Nyquist-Shannon sampling theorem

奈奎斯特定理（Nyquist-Shannon sampling theorem，常簡稱取樣定理）

是數位訊號處理中的核心基礎，主要說明如何將「連續的類比訊號」轉換成「離散的數位訊號」且在未來能完美還原而不失真。

它的核心觀念非常直接：**為了要能完整保留並還原一個訊號，你的「取樣頻率」必須嚴格大於該訊號中「最高頻率」的兩倍。**

以數學公式表示：


$$f_s > 2 f_{max}$$


（其中 $f_s$ 是取樣頻率，即每秒擷取訊號的次數；$f_{max}$ 是原訊號中包含的最高頻率）


## 以下是幾個理解這項定理的關鍵重點：

* **為什麼要乘以兩倍？**
  要描繪出一個波形（例如正弦波），你至少要在一個波的週期內抓到兩個點（最高點和最低點），才能大致知道這個波的震盪幅度和頻率。如果抓得比這更少，你就無法分辨這個波的真實樣貌。

* **如果不遵守會怎樣？（混疊現象 Aliasing）**
  如果取樣頻率太低（小於兩倍的最高頻率），在還原訊號時就會發生**混疊**。高頻的訊號會「偽裝」成低頻的訊號，導致聲音失真或影像破圖。

  * 一個生活中的視覺例子：
    * 當你看影片中的汽車高速行駛或直升機起飛時，有時輪框或螺旋槳看起來像在「倒轉」或「靜止」。這就是視覺上的混疊現象，因為攝影機每秒拍攝的幀數（取樣頻率）不夠快，抓不到輪胎真實的旋轉速度。

* **生活中的經典應用：音樂 CD**
人類耳朵能聽到的聲音頻率極限大約在 20,000 Hz (20 kHz)。根據奈奎斯特定理，要將人耳能聽到的所有聲音數位化並完美還原，錄音時的取樣頻率至少要大於 40,000 Hz。
這也是為什麼標準音樂 CD 的取樣頻率被統一制定在 **44,100 Hz (44.1 kHz)**——它大於 $20 \text{ kHz} \times 2$，同時保留了一點緩衝頻寬給防止高頻雜訊干擾的濾波器使用。
